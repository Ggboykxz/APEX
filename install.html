Installation

Install APEX

Two supported channels — npm and the native backend — plus Docker and a source checkout.

System Requirements

Minimum

  • Node 16+ for npm, or no runtime for the native backend
  • At least one API key (or Ollama for free local models)
  • Terminal with 256-color support
  • 100 MB disk space

Recommended

  • npm install for the apex command
  • Native backend for headless servers and CI
  • Git for version control integration
  • Ollama for free local models

Installation Methods

npm

All

Recommended. Installs the apex command; the wrapper downloads and verifies the native backend on first run. Zero runtime dependencies.

bash
npm install -g apex-ai
apex --version
Verify
apex --version
One-shot
apex run "Hello"

Platform Notes

macOS

  • • npm or the one-command installer: curl -fsSL https://apex-ai.dev/install.sh | bash
  • • Native backend: curl -fsSL https://apex-ai.dev/install.sh | bash -s -- --method native
  • • Terminal.app, iTerm2, Warp, Kitty all supported

Linux

  • • npm or the installer works on all distros
  • • Native backend for headless servers
  • • Docker for isolated environments

Windows

  • • npm: npm install -g apex-ai
  • • Native: irm https://apex-ai.dev/install.ps1 | iex
  • • Docker: docker run -it ghcr.io/ggboykxz/apex
  • • WSL2 recommended for the best terminal experience

Headless / CI

  • • Native backend: apex-rs serve
  • • Verified release assets with .sha256 sidecars
  • • Docker image for reproducible pipelines
  • • No TUI — use npm or a source checkout for that

Upgrade & Troubleshooting

Upgrade

bash
# npm
npm install -g apex-ai@latest

# native (verified download)
curl -fsSL https://apex-ai.dev/install.sh | bash

# source checkout
git pull

# Check version
apex --version

Common Issues

"command not found: apex"

Add the npm global bin directory (or ~/.apex/bin for the native backend) to your PATH, or set APEX_BINARY=/path/to/apex.

"Authentication failed"

Check your API key in ~/.apex/.env. Run echo $ANTHROPIC_API_KEY

APEX_INSTALL_METHOD rejected

pip, pipx and uv channels were removed. Unset the variable or set it to native.

Native download fails

Confirm the release has an asset for your target and that APEX_INSTALL_DIR is writable. Checksum mismatches abort before writing.
